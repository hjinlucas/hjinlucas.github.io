# Lucas Jin — Personal website

Bilingual static personal website, hosted at https://hjinlucas.github.io.

- `index.html`: English homepage.
- `zh/index.html`: Chinese homepage.
- `assets/style.css`: shared responsive layout.
- `assets/lucas.png`: owner's portrait, reused from their existing portfolio.

## Preview

Run `python3 -m http.server 8765` from this directory, then open http://localhost:8765.

## Publish

GitHub Pages publishes the root of the `main` branch. Push changes to update the site. No build tools or external services are required.

The site includes the owner's supplied introduction, current products, startup experience, education, volunteering, and media links. The English and Chinese pages are independent static documents; update both when changing content.
